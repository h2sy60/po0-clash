# 简洁界面

po0-clash 在各平台采用苹果官网式的简洁排版，由 Material 组件实现，决策见 [ADR 0016](../adr/0016-material3-performance.md)。
本文件保留原路径，以兼容已有文档链接；此前的液态玻璃风格见 [ADR 0010](../adr/0010-liquid-glass.md)。

## 视觉与组件

- 表面使用中性黑白灰，默认主操作使用蓝色；通过 `ColorScheme` 角色统一。尊重用户主题色、深色和纯黑设置。
- 内容、导航、弹窗使用不透明表面。移除背景模糊、饱和度滤镜、渐变描边和装饰性软阴影。
- `AppShape` 使用圆角矩形；`AppCorner` 的 extraSmall / small / medium / large / extraLarge 为 4 / 8 / 12 / 16 / 28。
- 侧栏使用简洁文字行，底栏和分段选择基于 Material 控件。连接状态用大字和留白突出，卡片默认不描边；操作按钮和状态保留明确文字。
- `lib/common/glass.dart` 与 `lib/widgets/glass.dart` 保留既有接口，内部使用 Material 角色色和表面，避免为改名扩大调用点差异。

## 操作结构

| 窗口宽度 | 布局 |
|---|---|
| < 600 dp | 底部 NavigationBar 位于页面下方，不覆盖内容和浮动操作按钮 |
| 600～839 dp | 左侧紧凑图标导航，右侧页面 |
| ≥ 840 dp | 文字侧栏；首页集中提供连接、模式、路由、当前节点、配置、加白和统计 |

首页在所有宽度都可进入；页面状态在窗口宽度变化时保留。内容较窄时纵向分组，宽度充足时使用两列。
桌面 TUN / 系统代理仍遵循 [ADR 0011](../adr/0011-exclusive-desktop-route.md)，加白总开关仍遵循 [ADR 0014](../adr/0014-unified-whitelist.md)。

## 刷新与性能

- Core 不可用、隐藏窗口或离开首页时停止纯 UI 统计；macOS 开启托盘网速时继续采样。恢复时显示最新数据，不重启代理或清零 Core 计数。
- 不可见页面与被禁用的 TickerMode 会停止页面轮询。流量图对未变化的采样不重新启动动画，并使用独立重绘边界。
- 白名单调度独立于界面可见性；Android 的亮灭屏约定、ggy 11 秒间隔和网络变化处理保持原有语义。
- 原生通信的缓存和队列优化见 ADR 0016；不能用微基准结果替代实际设备的整体性能测量。

## 图标

应用与托盘继续使用 P / 斜杠零标志，源文件位于 `assets_source/images/icon/`，由 `tool/generate_app_icons.sh` 生成。
本轮不更换应用身份或已安装应用的数据目录。
