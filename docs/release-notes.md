po0-clash v6.3.0：全新简洁界面，降低空闲资源消耗，并完善 Windows 自签名与启动诊断。

## 本次更新

- 界面采用黑白灰表面、蓝色主操作和清晰留白，重整桌面侧栏、手机底栏及首页信息分组，支持浅色、深色和纯黑模式
- 移除背景模糊和装饰性玻璃效果，未变化的流量图不再反复启动动画
- 窗口隐藏、最小化或离开首页时暂停纯界面统计，恢复后读取最新数据；代理、自动加白和已开启的 macOS 托盘网速继续运行
- 减少进程通信中的空闲唤醒、临时内存分配和数据复制，复用未变化的节点数据
- 重新聚焦窗口时不再重复触发已有的加白轮询，po0 配置间隔、ggy 固定 11 秒间隔及网络变化处理保持原有行为
- 清理遗留的 FlClash 应用描述，上游项目和贡献者保留在独立的开源署名区域
- Windows 主程序、Core、Helper、安装器和卸载器使用固定证书自签名并添加时间戳，附公钥证书与 SHA-256 校验清单
- Windows 启动失败会分别提示杀毒拦截、签名验证失败和应用控制策略限制，并保留原始错误码

## 升级说明

- 从旧版 po0-clash 直接覆盖安装即可，已有配置、节点、加白设置与 token 保留
- 桌面端新增独立首页，连接、模式、路由、节点和流量统计集中在首页，侧栏用于切换页面
- 界面统计暂停不会停止代理，也不会清零 Core 的累计流量

## 安装

- Windows：po0-clash-6.3.0-windows-amd64-setup.exe（安装包）或 po0-clash-6.3.0-windows-amd64.zip（免安装）
- Windows 校验：发布页提供 po0-clash-signing.cer 和 po0-clash-6.3.0-windows-amd64-sha256.txt，包内另附 WINDOWS-SECURITY.txt
- macOS：curl -fsSL https://raw.githubusercontent.com/yuuuki-creation/po0-clash/main/scripts/install-macos.sh | bash
- Android：po0-clash-6.3.0-android-arm64-v8a.apk（主流机型），另提供 armeabi-v7a 和 x86_64 版本

## 已知限制

- 自签名提供完整性与发布者连续性，不会自动获得 Windows 信任，也不保证通过 SmartScreen、智能应用控制或杀毒检测；安装程序不会自动导入根证书或关闭安全策略
- 实际 CPU、内存和耗电改善取决于设备与使用状态，不承诺统一的下降比例
- 「手动节点」配置在每次增删改节点时按模板整体重写，直接编辑这份配置文件的改动不会保留；调整规则请使用「覆写」
- 带端口的订阅地址（例如 https://example.com:8443/sub）如果粘贴进「分享链接」，会被当作一个 HTTP 代理节点导入
- ggy 加白链接每次请求都会写入；日志里持续出现 evicted 说明白名单在被反复挤占
- Android 从最近任务划掉 po0-clash 后停止检查，重新打开应用即恢复
- 同时在用的网段超过白名单容量（po0 为 5 条，服务端已有的固定记录也占名额）时，各设备会互相挤占
- 与其他代理客户端同时开启系统代理或 TUN 会互相抢占，请只在一个应用里开启
- macOS 版本未经 Apple 公证，安装脚本会移除隔离属性；每次更新后首次开启虚拟网卡需重新输入管理员密码
