po0-clash v6.4.0：同步 FlClash v0.9.1 界面，修复 Android 快捷启动加白并刷新升级后的图标。

## 本次更新

- 同步 FlClash v0.9.1 的配色、字体、图标、连续圆角、桌面侧栏及手机悬浮底栏，po0 加白页面沿用同一套组件
- 首页采用上游状态卡、连接按钮、流量曲线、出站模式、订阅用量及服务检测布局，桌面按窗口宽度排列卡片，手机可调整卡片顺序
- 新增出口 IP 类型与质量查询，节点分组标签、选中标记和桌面连接表格同步上游交互
- 修复 Android 下拉快捷开关或桌面快捷方式冷启动代理后不运行加白的问题；已开启加白时自动初始化客户端并恢复原有调度，无需再手动打开
- 快捷启动初始化期间仍由原生服务处理最新启停操作，初始化完成不会重新启动已被用户停止的代理
- 升级后刷新 Android 启动器入口、已固定的开关快捷方式及下拉磁贴图标，兼容早期版本保留旧图标的情况
- 保留页面隐藏时暂停界面统计的行为，加白间隔、屏幕状态调度和直连请求保护继续沿用原有逻辑

## 升级说明

- 从旧版 po0-clash 直接覆盖安装，已有配置、节点与加白设置保留；Android 构建号递增，签名及应用 ID 保持一致
- Android 快捷启动恢复加白需要之前已开启加白并接受使用声明；首次使用或启动恢复提示仍需在客户端完成
- 启动器图标缓存行为因手机系统而异，更新后若仍显示旧图标，可先正常打开一次应用再检查

## 安装

- Windows：po0-clash-6.4.0-windows-amd64-setup.exe（安装包）或 po0-clash-6.4.0-windows-amd64.zip（免安装）
- Windows 校验：发布页提供 po0-clash-signing.cer 和 po0-clash-6.4.0-windows-amd64-sha256.txt，包内附 WINDOWS-SECURITY.txt
- macOS：curl -fsSL https://raw.githubusercontent.com/yuuuki-creation/po0-clash/main/scripts/install-macos.sh | bash
- Android：po0-clash-6.4.0-android-arm64-v8a.apk（主流机型），另提供 armeabi-v7a 和 x86_64 版本

## 已知限制

- 自签名提供完整性与发布者连续性，不会自动获得 Windows 信任，也不保证通过 SmartScreen、智能应用控制或杀毒检测；安装程序不会自动导入根证书或关闭安全策略
- Android 从最近任务划掉客户端可能停止加白调度，再次通过快捷方式启动代理或打开客户端会重新初始化；系统强行停止应用后仍需手动打开
- 「手动节点」配置在每次增删改节点时按模板整体重写，直接编辑这份配置文件的改动不会保留；调整规则请使用「覆写」
- 带端口的订阅地址如果粘贴进「分享链接」，会被当作一个 HTTP 代理节点导入
- ggy 加白链接每次请求都会写入，固定每 11 秒检查；日志里持续出现 evicted 说明白名单在被反复挤占
- 同时使用的网段超过白名单容量时，各设备会互相挤占；与其他代理客户端同时开启系统代理或 TUN 也会互相抢占
- macOS 版本未经 Apple 公证，安装脚本会移除隔离属性；每次更新后首次开启虚拟网卡需重新输入管理员密码
